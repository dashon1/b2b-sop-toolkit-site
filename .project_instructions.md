# B2B Compliance-Ready SOP Toolkit - Sales Page

## Overview
Static sales/landing page for a B2B digital product: Compliance-Ready SOP Toolkit targeting healthcare (HIPAA), finance (SOC 2), and legal regulated industries.

## Visual Identity
- **Color palette**: Deep navy (#1a2332), compliance blue (#2563eb), trust green (#10b981), warning amber (#f59e0b), professional white/gray
- **Typography**: Inter (headings/sans), Work Sans (display), JetBrains Mono (mono)
- **Theme**: Corporate professional with geometric elements, structured grid layouts, regulatory compliance aesthetic
- **Light theme only** (dark mode disabled)

## Custom CSS Variables
- Primary color overridden to compliance blue (217 89% 53%)
- Custom Tailwind colors: navy, compliance-blue, trust-green, warning-amber (with full shade scales)

## Page Structure
1. Fixed navigation bar with smooth scroll links
2. Hero section (dark navy gradient + CDN background image)
3. Problem section (pain points with icons)
4. Solution/mechanism section (4 feature cards)
5. What's Inside section (4 deliverable categories with image)
6. Pricing section (2 tiers: Essential $67, Complete $147)
7. Social proof/testimonials section (dark navy bg)
8. FAQ section (accordion-style)
9. Final CTA section (dark gradient)
10. Footer with legal disclaimer

## Technical Notes
- No database (static content only)
- All interactive components use 'use client' directive
- ScrollAnimate wrapper component for viewport-triggered animations
- Framer Motion for animations, react-intersection-observer for scroll triggers
- ZIP product file copied to public/ directory
- CTAs show toast notifications (checkout placeholder)
